Setting Up the LangChain Environment for Generative AI: Part 2

Adnan Rahin
2 min read
·
Oct 17, 2024
--




Before diving into the LangChain framework, we need to complete some prep work, such as setting up the correct Python version and installing the necessary dependencies. I’ll also create a Git repository where I will keep updating all the related projects.

After testing different versions, I found that Python 3.11.3 works quite well with LangChain. For development, I recommend using Jupyter Notebook, as it provides an interactive environment that makes analyzing Python script outputs much easier compared to standalone Python scripts.

Required Dependencies

Here’s a list of the dependencies we’ll need to set up our environment:

openai==1.30.5
pymysql==1.1.0

langchain-google-genai==1.0.5

langchain-text-splitters==0.2.0
langchainhub==0.1.17
We’ll install these packages upfront. Though we might not need all of them right away, this will ensure our environment is fully prepared. If any additional dependencies are required later, we can install them as we go.

Step 1: Install Miniconda
To get started, make sure Miniconda is installed. You can follow the instructions from the official Miniconda installation guide. Once installed, verify the installation by running:

conda - version

Step 2: Create a Conda Environment
After confirming that Miniconda is properly set up, we’ll create a new environment called gen_ai_envs using Python 3.11.3:

conda create -n gen_ai_envs python=3.11.3
Once the environment is created, activate it with:

conda activate gen_ai_envs
Step 3: Clone the Git Repository
Next, we’ll clone the project repository and install the required dependencies. Run the following commands:

git clone https://github.com/adnanrahin/genai-with-langchain.git
cd genai-with-langchain
pip install -r requirements.txt

The installation process may take a few minutes, so take a short break while the packages install.

Step 4: Start Jupyter Notebook
Once the installation is complete, we can start the **Jupyter Notebook** server to begin coding:

jupyter notebook

With the environment set up and the Jupyter Notebook running, we’re now ready to dive into LangChain!
